## ✨ Features

* **Offline-First & Local Privacy**: All bookmarks and board settings persist locally in the browser (`localStorage`). Features simple JSON backup import/export.
* **Ambient Lumen Design**: Real-time cursor-reactive glow effects, card 3D tilt, and interactive particles.
* **Bento Grid & Boards**: Organizable columns for boards and custom categories, allowing cross-board link movement.
* **Instant Command Palette (`Ctrl+K`)**: Keyboard-centric search and actions launcher.
* **Privacy Mode**: Instant blur toggle for sensitive titles and URLs.

## 🛠️ Quick Start

```bash
# Install dependencies
npm install

# Start local dev server
npm run dev
```
